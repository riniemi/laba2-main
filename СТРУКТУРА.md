    ├── common.cpp               реализация common.h

    ├── slist.cpp                односвязный список
    ├── dlist.cpp                двусвязный список
    ├── stack.cpp                стек

    ├── io.cpp                   ввод

    ├── task2_set/main.cpp       задача 2: множество с командами

## Библиотека структур (`include/` + `src/`)

Каждая структура — пара «заголовок + реализация», собираются в статическую библиотеку `build/liblab.a`.

| Файл | Что реализует | Ключевые методы |
|---|---|---|
| `massiv` | Динамический массив строк (с удвоением ёмкости) | `insert`, `push`, `get`, `set`, `erase` |
| `slist` | Односвязный список | `pushHead`, `pushTail`, `popHead`, `popTail`, `delValue`, `find` |
| `dlist` | Двусвязный список | `pushHead`, `popTail`, `delValue`, `moveToHead`, `pushHeadNode` |
| `stack` | Стек (LIFO) поверх `SList` | `push`, `pop`, `top` |
| `queue` | Очередь (FIFO) поверх `SList` | `push`, `pop` |
| `tree` | Полное бинарное дерево + обходы + отрисовка | `insert`, `contains`, `isComplete`, `traverse`, `show` |
| `bst` | Двоичное дерево поиска (числа) | `insert` (возвращает глубину) |
| `hashfn` | Хеш-функции djb2 и FNV-1a | `hashDjb2`, `hashFnv1a` |
| `hashtable` | Хеш-таблица (открытая адресация) + Блум | `put`, `get`, `contains`, `erase`, `stats`, `dump`/`load` |
| `bloom` | Фильтр Блума | `add`, `mightContain`, `setBits` |
| `hashset` | Множество методом цепочек | `add`, `remove`, `contains`, `items` |
| `lru` | LRU-кэш (хеш-таблица + двусвязный список) | `set`, `get`, `show` |
| `common` | Утилиты: ошибки, разбор токенов, числа | `fail`, `tokenize`, `quote`, `upper` |
| `io` | Чтение всего ввода | `readInput` |

## Соответствие задач и структур

| Задача | Что делает | Использует |
|---|---|---|
| `task1_xml` | Проверяет/исправляет строку тегов | `Stack`, `SList` |
| `task2_set` | Команды над множествами + сохранение в файл | `HashSet`, `hashfn` |
| `task3_genome` | Считает общие пары двух строк A–Z | `HashSet` |
| `task4_stress` | Считает ошибки расстановки ударений | `HashSet`, `Array` |
| `task5_bst` | Печатает глубину вставки чисел | `BST` |
| `task6_bench` | Сравнивает теорию и эксперимент по пробам | `HashTable`, `BloomFilter`, `hashfn` |
| `task6_hash` | REPL для хеш-таблицы (`HNEW/HSET/...`) | `HashTable`, `Array` |
| `task7_lru` | Кэш с вытеснением самого давнего | `LRUCache`, `DList`, `HashTable` |

## Точки входа (`main`)

Каждая задача — отдельный `main.cpp` со своей `main()`. Из них собираются отдельные
исполняемые файлы в `bin/cpp/` (общие структуры берутся из `build/liblab.a`).

- Задачи с командами через аргументы: `task2_set`, `task6_hash` — ключи `--file` и `--query`.
- Задачи, читающие данные из файла или stdin: `task1_xml`, `task3_genome`, `task4_stress`,
  `task5_bst`, `task7_lru` — ключ `--file` (без него читается stdin).
- Эксперимент: `task6_bench` — ключи `--cap`, `--seed`, `--samples`.

## Служебные каталоги (создаются сборкой)

- `build/` — объектные файлы (`*.o`), зависимости (`*.d`) и архив `liblab.a`.
- `bin/cpp/` — готовые исполняемые файлы задач.

Эти каталоги удаляются командой `make clean`.
