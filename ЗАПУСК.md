# Как собрать и запустить

Все команды выполняются из корня проекта (`laba2-main/`).

## Требования

- Компилятор `g++` с поддержкой C++17
- `make`

## Сборка

```bash
make cpp
```

Что произойдёт:

1. Компилируются все `src/*.cpp` → объектные файлы в `build/`.
2. Из них собирается статическая библиотека `build/liblab.a`.
3. Каждый `src/task*/main.cpp` линкуется с библиотекой → программа в `bin/cpp/`.

Итог — исполняемые файлы:

```
bin/cpp/task1_xml
bin/cpp/task2_set
bin/cpp/task3_genome
bin/cpp/task4_stress
bin/cpp/task5_bst
bin/cpp/task6_bench
bin/cpp/task6_hash
bin/cpp/task7_lru
```

Удалить результаты сборки:

```bash
make clean
```

> **Важно.** В Makefile есть цели `all` (собирает C++ и Go) и `demo` (запускает `demo.sh`),
> но каталога `go/` и файла `demo.sh` в проекте нет. Поэтому обычная команда `make`
> и `make demo` завершатся ошибкой. Используй `make cpp`.

## Общие правила ввода

Программы читают данные двумя способами:

- из файла: ключ `--file путь` (`--file file.data`);
- из стандартного ввода, если `--file` не задан: `echo '...' | ./bin/cpp/<задача>`.

---

## Задача 1 — `task1_xml` (проверка тегов)

Читает первую строку, пытается исправить один символ так, чтобы строка из тегов
стала корректной, и печатает результат (или `Incorrect`).

```bash
echo '<a></b>' | ./bin/cpp/task1_xml
# <a></a>
```

## Задача 2 — `task2_set` (множества)

Команды (через `--query`), данные хранятся в `--file`:

- `SETADD <имя> <значение>` — добавить;
- `SETDEL <имя> <значение>` — удалить;
- `SET_AT <имя> <значение>` — проверить наличие;
- `PRINT <имя>` — вывести множество.

```bash
./bin/cpp/task2_set --file file.data --query 'SETADD A one'   # TRUE
./bin/cpp/task2_set --file file.data --query 'SETADD A one'   # FALSE (уже есть)
./bin/cpp/task2_set --file file.data --query 'SET_AT A one'   # TRUE
./bin/cpp/task2_set --file file.data --query 'PRINT A'        # {one}
./bin/cpp/task2_set --file file.data --query 'SETDEL A one'   # TRUE
```

`SETADD` и `SETDEL` сохраняют состояние в файл; остальные команды — только читают.

## Задача 3 — `task3_genome` (геномы)

Две строки из заглавных букв A–Z. Печатает число пар первого генома, которые
встречаются во втором.

```bash
printf 'ABAB\nABBA\n' | ./bin/cpp/task3_genome
# 3
```

## Задача 4 — `task4_stress` (ударения)

Первая строка — число слов словаря N, затем N слов словаря (в правильной расстановке
ударений, например `cAnnot`), затем текст. Печатает число ошибок.

```bash
printf '2 cAnnot hello\ncannOt hello world\n' | ./bin/cpp/task4_stress
# 2   (в "cannOt" не то ударение, в "world" нет ни одного)
```

## Задача 5 — `task5_bst` (BST)

Последовательность целых чисел, `0` завершает ввод. Для каждого нового числа печатает
его глубину (корень — 1); повторы пропускаются.

```bash
echo '5 3 8 3 0' | ./bin/cpp/task5_bst
# 1 2 2
```

## Задача 6 — `task6_bench` (эксперимент)

Сравнивает среднее число проб в хеш-таблице с формулами Кнута и показывает эффект
фильтра Блума. Ключи: `--cap` (число ячеек), `--seed` (генератор), `--samples` (число запросов).

```bash
./bin/cpp/task6_bench --cap 1009 --samples 5000 --seed 1
```

По умолчанию `--cap 100003`, `--samples 20000` — это дольше.

## Задача 6 — `task6_hash` (REPL хеш-таблицы)

Команды (через `--query`), состояние в `--file`:

- `HNEW <имя> <linear|double>` — создать таблицу;
- `HSET <имя> <ключ> <значение>` — задать;
- `HGET <имя> <ключ>` — получить (или `NOT FOUND`);
- `HHAS <имя> <ключ>` — есть ли ключ;
- `HDEL <имя> <ключ>` — удалить;
- `HLEN <имя>` — число элементов;
- `PRINT <имя>` — все занятые ячейки;
- `HSTATS <имя>` — параметры таблицы и фильтра.

```bash
printf 'HT t double 11 0 0\n' > file.data
./bin/cpp/task6_hash --file file.data --query 'HSET t apple red'  # red
./bin/cpp/task6_hash --file file.data --query 'HGET t apple'      # red
./bin/cpp/task6_hash --file file.data --query 'HLEN t'            # 1
./bin/cpp/task6_hash --file file.data --query 'HHAS t apple'      # TRUE
./bin/cpp/task6_hash --file file.data --query 'HDEL t apple'      # TRUE
./bin/cpp/task6_hash --file file.data --query 'HSTATS t'          # таблица параметров
```

Команды, изменяющие таблицу (`HNEW`, `HSET`, `HDEL`), сохраняют файл; остальные — читают.

## Задача 7 — `task7_lru` (LRU-кэш)

Ввод: `cap <N>` (ёмкость), `q <Q>` (число запросов), затем `Q` запросов вида
`SET <ключ> <значение>` и `GET <ключ>`. Печатает результаты всех `GET` через пробел
(`-1`, если ключа нет). Ключ `--trace` печатает состояние кэша после каждого запроса.
Запятые и `=` во вводе считаются пробелами, поэтому можно писать и `cap=2, q=3`.

```bash
echo 'cap 2 q 3 SET a 1 GET a GET b' | ./bin/cpp/task7_lru
# 1 -1

echo 'cap 2 q 3 SET a 1 GET a GET b' | ./bin/cpp/task7_lru --trace
# печатает состояние кэша после каждого запроса
```
